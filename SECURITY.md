# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |

Security fixes are released as a new 3.x version. To get them, upgrade to the latest 3.x release.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/GeorgeHulpoi/payload-totp/security/advisories/new) ("Report a vulnerability" on the repository's Security tab).

Please include:

- the affected version(s) of `payload-totp` and Payload
- the plugin options in use (e.g. `forceSetup`, `disableAccessWrapper`)
- steps to reproduce, or a proof of concept
- the impact, as you understand it

## What to expect

- You will receive a reply within 7 days.
- Once the report is confirmed, we will work on a fix and keep you informed of progress.
- We follow coordinated disclosure: please keep the details private until a fixed version is released, or until 90 days after the report, whichever comes first.
- When the fix is released, we publish a GitHub security advisory (with a CVE where applicable) and credit you, unless you prefer to remain anonymous.
